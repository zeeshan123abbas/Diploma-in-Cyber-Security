## ⚖️ Ethics First

Everything in this repository is for learning defence. Practise only on machines and networks you own or have written permission to test (your own virtual machines, a home lab, simulators and legal practice platforms). Unauthorised access, scanning or interception is illegal under Pakistan's Prevention of Electronic Crimes Act (PECA) 2016 and similar laws in other countries.

## 🗺 How to Use This Repository

1. Open a term, then a module, then work through the sessions in order.
2. Run every example yourself; the code files sit next to each session's notes.
3. Do the lab tasks and assignment before moving on.
