> Diploma in Cybersecurity and Digital Forensics · Term 1 · about 8 months · 3 sessions a week, 2 hours each · [⬅ Repository Home](../README.md)

Term 1 builds the foundation every security professional needs. You start by learning to think like a programmer (C, then HTML5 and JavaScript), move on to how networks are built and configured, and then step into the security world: frameworks and laws, ethical hacking, data protection and privacy. The term ends with a capstone project in which you design and document a secure network for a realistic organisation.

## 🎯 Learning Outcomes

By the end of Term 1 you will be able to:

- Write structured C programs using variables, decisions, loops, functions, arrays and pointers
- Build interactive web pages with HTML5, CSS3 and modern JavaScript
- Explain network models, cabling, IP addressing, protocols, routing and switching
- Configure routers and switches (VLANs, routing, DHCP, ACLs, IPv6) in Cisco Packet Tracer
- Explain GDPR, cyber laws and how digital evidence must be handled
- Describe the ethical hacking process, common attacks and the matching defences
- Protect sensitive data, run a privacy impact assessment and discuss ethical issues
- Map security controls to frameworks such as the NIST CSF and ISO/IEC 27001
- Design, secure and document a small enterprise network (capstone project)

## 🧪 Lab Rules (read first)

All practical work in this course is done **only** on systems you own or have written permission to test: your own virtual machines, your own home lab, the Packet Tracer simulator, or legal practice platforms. Never scan, attack or sniff networks that do not belong to you. Unauthorised access is a crime under Pakistan's Prevention of Electronic Crimes Act (PECA) 2016 and similar laws worldwide.

## 🗺 How to Study

1. Follow the modules in order; each one builds on the previous.
2. For each session: read **Concepts Explained**, type (do not copy-paste) the **Code Examples**, then do the **Lab Practice**.
3. Answer the **Quick Quiz** before opening the answers.
4. Keep a lab notebook (or a GitHub repo) with your assignments and screenshots.
5. Practice sessions are revision labs; use them to fill gaps before the module exam.
6. Start thinking about your capstone network early, from the networking modules onwards.
